# Arcade Arena — Run Sheet (one page)

**For the caretaker / teacher. No training needed. Target: laptop closed to game
running in under 60 seconds.**

## You need

- A laptop with a webcam.
- A projector or TV, connected and showing the laptop screen.
- Space for the class to stand (or sit) facing the camera.

## Start (about 60 seconds)

1. **Open the laptop.** Connect the projector/TV (usually the `🖥️`/Windows+P or
   the display button). You should see the laptop screen on the wall.
2. **Open the game.** Double-click the **Arcade Arena** icon, or open the browser
   to the game address on the card taped to the laptop.
3. **Pick a show and Stand or Sit.** Tap one of the three big cards, then **Stand**
   or **Sit**. Type the class name (e.g. `Room 12`) if it isn't already there.
4. **Tap "📷 Allow camera & Start".** If the browser asks to use the camera, tap
   **Allow**. (The camera never records or sends anything — it says so on screen
   the whole time.)
5. **Tap the big ▶ START.** Put the laptop where the camera can see the whole
   group.

## Play

- **"Stand still"** appears for ~5 seconds — get everyone to hold still so the
  game can measure them. Then it starts on its own.
- The character calls the moves. Kids **copy the move** — jump, duck, reach,
  step. Right in the room is right on the screen.
- The score at the top is the **whole class's** score. There are no individual
  scores or names.
- To finish, tap the **■** button (bottom-right). The class score shows.

## If something looks wrong

- **Kids look laggy / choppy:** the game lowers quality by itself. Just keep
  going — it will smooth out. Closing other browser tabs helps.
- **No one is detected:** make sure the camera can see everyone head-to-hip
  (or head-to-waist if seated), and the room isn't backlit by a bright window.
  Re-tap **▶ START** to re-measure.
- **Sound cuts out on bad wifi:** it won't — the game works fully offline once
  it has loaded once. If there is no sound at all, tap the screen once (browsers
  need one tap before they allow sound).
- **Camera light won't turn off after:** close the browser tab; the light goes
  off with it.

## Seated groups

Choose **Sit** at step 3. Same game, same moves from the waist up, same score.
